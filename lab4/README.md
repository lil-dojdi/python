### Задание 1: Проверка валидности номера телефона

**Описание:**  
Программа проверяет корректность номера телефона из Молдовы в различных форматах. Используются регулярные выражения для точного сопоставления паттернов. Программа работает в бесконечном цикле, запрашивая ввод до тех пор, пока не будет введен правильный номер. При успешной проверке выводится сообщение с номером.

**Объяснение выполнения:**  
- **Импорт модуля:** Используется модуль `re` для работы с регулярными выражениями.  
  ```python
  import re
  ```
- **Определение паттернов:** Создан список паттернов для каждого допустимого формата. Например, `r'^00373\d{8}$'` проверяет строку, начинающуюся с "00373" и содержащую ровно 8 цифр после.  
  ```python
  patterns = [
      r'^00373\d{8}$',  # 00373 + 8 цифр
      r'^\+373\d{8}$',  # +373 + 8 цифр
      r'^\d{8}$',       # 8 цифр
      r'^0\d{8}$'       # 0 + 8 цифр
  ]
  ```
- **Цикл проверки:** В цикле `while True` запрашивается ввод. Для каждого паттерна проверяется соответствие с помощью `re.match()`. Если совпадение найдено, выводится успех и цикл прерывается. Если ни один паттерн не подошел, вызывается `ValueError`. Блок `try-except` обрабатывает ошибки, выводя сообщение и продолжая цикл.  
  ```python
  while True:
      try:
          phone = input("Введите номер телефона: ")
          for pattern in patterns:
              if re.match(pattern, phone):
                  print(f"Номер {phone} корректен. Отлично!")
                  break
          else:
              raise ValueError("Неверный формат номера телефона.")
          break
      except ValueError as e:
          print(e)
          continue
  ```
