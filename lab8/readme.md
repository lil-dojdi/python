## Приложение на Python: преобразование текста в речь (gTTS)

---

## 📌 Цель работы

Создать приложение на Python, которое преобразует текст, введённый пользователем, в аудиофайл формата `.mp3` с использованием библиотеки **gTTS**.

---

## 📂 Используемые технологии

- используется библиотека:
  - gTTS (Google Text-to-Speech)  
  - os (работа с файлами)  

---

## 📦 Установка

Установите библиотеку gTTS:

    pip install gtts

---

## 📌 Описание программы

Программа:

- предлагает выбрать способ ввода текста  
- считывает текст (с клавиатуры или из файла)  
- проверяет корректность данных  
- проверяет, что текст не пустой  
- позволяет выбрать язык  
- проверяет поддержку языка  
- преобразует текст в речь  
- сохраняет результат в файл `.mp3`  
- обрабатывает ошибки  

---

## 📥 1. Выбор способа ввода

    choice = input("Ваш выбор (1/2): ")

## ✍️ 2. Получение текста

Ввод с клавиатуры:

    text = input("Введите текст: ")

Чтение из файла:

    with open(file_path, "r", encoding="utf-8") as f:
        text = f.read()

---

## ⚠️ 3. Проверка данных

    if not os.path.exists(file_path):
        raise FileNotFoundError("Файл не найден!")

    if os.path.getsize(file_path) == 0:
        raise ValueError("Файл пустой!")

    if not text.strip():
        raise ValueError("Текст пустой!")

---

## 🌍 4. Выбор языка

    languages = tts_langs()
    lang_choice = input("Введите код языка: ")

    if lang_choice not in languages:
        print("Ошибка: язык не поддерживается!")

---

## 🔊 5. Генерация аудио

    tts = gTTS(text=text, lang=lang_choice, slow=False)
    tts.save("output.mp3")

---

## ✔️ 6. Проверка результата

    if not os.path.exists("output.mp3") or os.path.getsize("output.mp3") == 0:
        raise Exception("Ошибка создания аудиофайла!")
