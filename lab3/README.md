### Задание 1: Калькулятор идеального веса

**Описание:**
Код запрашивает у пользователя возраст, рост, пол и текущий вес, валидирует вводимые значения, рассчитывает идеальный вес по формуле Лоренца и выводит рекомендацию.

**Основные действия:**
- Запрос данных пользователя через input.
- Проверка корректности введённых данных.
- Расчёт идеального веса по формуле.
- Вывод результата и рекомендации.

**Пример кода:**
```python
from ideal_weight import get_valid_input, calculate_ideal_weight, get_recommendation

print("Калькулятор идеального веса (формула Лоренца)")

age = get_valid_input("Возраст (20–120 лет): ", 20, 120)
height = get_valid_input("Рост (150–220 см): ", 150, 220, float)
gender = get_valid_input("Пол (1 - Мужской, 2 - Женский): ", 1, 2)
actual_weight = get_valid_input("Текущий вес (45–300 кг): ", 45, 300, float)

gender = "M" if gender == 1 else "F"
ideal_weight = calculate_ideal_weight(height, age, gender)
recommendation = get_recommendation(actual_weight, ideal_weight)

print(f"\nВаш идеальный вес: {ideal_weight:.2f} кг")
print(recommendation)
```
**Пример вывода:**
```
Калькулятор идеального веса (формула Лоренца)
Возраст (20–120 лет): 25
Рост (150–220 см): 180
Пол (1 - Мужской, 2 - Женский): 1
Текущий вес (45–300 кг): 90

Ваш идеальный вес: 74.50 кг
Ваш вес выше положенного на 15.50 кг. Рекомендуется снизить вес.
```

### Задание 2: Калькулятор возраста кошки

**Описание:**
Код спрашивает, меньше ли кошке года, и в зависимости от ответа либо использует словарь соответствий месяцев и человеческих лет, либо рассчитывает возраст по формуле. Все вводимые значения проверяются.

**Основные действия:**
- Запрос возраста кошки (меньше года или нет).
- Ввод месяцев или лет, в зависимости от ответа.
- Проверка корректности введённых данных.
- Расчёт возраста кошки в "человеческих" годах.
- Вывод результата.

**Пример кода:**
```python
from cat_age import validate_input, calculate_kitten_age, calculate_adult_cat_age

print("Калькулятор возраста кошки в человеческих годах")

is_kitten = input("Кошке меньше года? (Да/Нет): ").strip().lower()
if is_kitten in {"да", "yes"}:
    months = validate_input("Сколько месяцев кошке? (1–11): ", 1, 11)
    human_age = calculate_kitten_age(months)
    print(f"Возраст кошки в человеческих годах: {human_age}")
else:
    years = validate_input("Сколько лет кошке? (1–35): ", 1, 35)
    human_age = calculate_adult_cat_age(years)
    print(f"Возраст кошки в человеческих годах: {human_age} лет")
```
**Пример вывода:**
```
Калькулятор возраста кошки в человеческих годах
Кошке меньше года? (Да/Нет): да
Сколько месяцев кошке? (1–11): 6
Возраст кошки в человеческих годах: 14 лет
```

### Задание 3: Список покупок

**Описание:**
Код реализует меню для работы со списком покупок: пользователь может добавить товар, удалить по номеру или названию, вывести список. Все действия валидируются.

**Основные действия:**
- Вывод меню с опциями.
- Добавление товара (с проверкой на повтор).
- Удаление товара по номеру или названию (с проверкой).
- Вывод списка товаров.
- Проверка корректности выбора пользователя.

**Пример кода:**
```python
from shopping_list import add_item, remove_item, display_list

shopping_list = []
while True:
    print("\nМеню:")
    print("1. Вывести список текущих товаров")
    print("2. Добавить товар в список")
    print("3. Удалить товар из списка")
    print("4. Выход")

    choice = input("Выберите опцию (1–4): ").strip()
    if choice == "1":
        display_list(shopping_list)
    elif choice == "2":
        item = input("Введите название товара: ").strip()
        add_item(shopping_list, item)
    elif choice == "3":
        method = input("Удалить по номеру (1) или названию (2)? ").strip()
        if method == "1":
            try:
                index = int(input("Введите номер товара: ").strip())
                remove_item(shopping_list, index)
            except ValueError:
                print("Неверный ввод. Введите число.")
        elif method == "2":
            name = input("Введите название товара: ").strip()
            remove_item(shopping_list, name)
        else:
            print("Неверный выбор метода удаления.")
    elif choice == "4":
        print("Выход из программы.")
        break
    else:
        print("Неверный выбор. Попробуйте снова.")
```
**Пример вывода:**
```
Меню:
1. Вывести список текущих товаров
2. Добавить товар в список
3. Удалить товар из списка
4. Выход
Выберите опцию (1–4): 2
Введите название товара: Молоко
Товар 'Молоко' добавлен в список.
Выберите опцию (1–4): 1
Текущий список покупок:
1. Молоко
```
