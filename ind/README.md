# CV Generator — Программный комплекс для создания резюме

Индивидуальный проект по разработке десктопного приложения на языке Python для автоматизации процесса создания профессиональных резюме в формате PDF.

---

## О проекте

Приложение предоставляет графический интерфейс (GUI) для ввода персональных данных, управления опытом работы и навыками, а также генерации стилизованного документа. Проект демонстрирует навыки работы с внешними библиотеками, файловой системой, регулярными выражениями и графическими фреймворками.

---

## Основной функционал

*   **Графический интерфейс:** Удобные формы ввода на базе Tkinter с использованием современных стилей оформления.
*   **Валидация данных:** Автоматическая проверка корректности Email и номера телефона перед сохранением.
*   **Работа с данными:** Возможность сохранения введенной информации в JSON-файл и её последующая загрузка.
*   **Генерация PDF:** Создание двухколоночного документа с поддержкой кириллицы и вставкой фотографии.
*   **Кастомизация:** Использование внешних шрифтов (DejaVu) для обеспечения корректного отображения текста.

---

## Технологический стек

*   **Язык программирования:** Python 3.
*   **GUI Фреймворк:** Tkinter (ttk).
*   **Генерация документов:** ReportLab.
*   **Формат хранения данных:** JSON.
*   **Обработка изображений:** Стандартные средства работы с путями и Tkinter PhotoImage.

---

## Установка и запуск

Для работы приложения необходимо наличие Python и установленной библиотеки ReportLab.

1. Установите зависимость:
   pip install reportlab

2. Убедитесь в наличии папки со шрифтами:
   Проект ожидает наличие папки `dejavu-fonts-ttf-2.37` в корневой директории для корректной генерации PDF.

3. Запустите приложение:
   python main.py

---

## Структура приложения

*   **Модель данных (Class User):** Объектно-ориентированный подход к хранению информации о пользователе.
*   **Блок валидации:** Использование регулярных выражений для контроля качества входных данных.
*   **Модуль генерации (generate_pdf):** Настройка стилей ParagraphStyle и верстка табличной структуры документа.
*   **Интерфейс (create_gui):** Реализация прокручиваемого контейнера, карточной системы ввода и предпросмотра фото.

---

## Использование

*   Введите свои данные в соответствующие поля.
*   Загрузите фотографию (поддерживаются форматы .png, .jpg, .jpeg).
*   Используйте кнопку «Сохранить» для локального кэширования данных в файл `user.json`.
*   Нажмите «Создать PDF», чтобы получить готовый файл `CV.pdf` в папке проекта.
